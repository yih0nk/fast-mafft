# Benchmark data

`bash bench/get_data.sh` downloads the exact inputs used in [RESULTS.md](../RESULTS.md) from this
repository's `data-v1` release and checks them against [DATA_MD5.txt](DATA_MD5.txt). All inputs are
unaligned FASTA.

## Real data

| file | sequences | source |
|---|---:|---|
| `data/rnasim1k.fa`, `rnasim2k.fa`, `rnasim5k.fa` | 1,000 / 2,000 / 5,000 | Random subsets (seeds 1, 2, 5; original order kept) of `rnasim10k.fa` |
| `data/rnasim10k.fa` | 10,000 | RNASim `10000_R_1/R0/true_align.txt` with gaps removed |
| `data/large/rnasim20k.fa`, `rnasim50k.fa` | 20,000 / 50,000 | RNASim `20000_R_1`, `50000_R_1`, gaps removed |
| `data/large/rnasim25k.fa` | 25,000 | Random subset (fixed seed) of `rnasim50k.fa` |
| `data/large/16S.T.fa`, `16S.3.fa`, `16S.B.ALL.fa` | 7,350 / 6,323 / 27,643 | 16S rRNA sets (`cleaned.alignment.fasta`), gaps removed |
| `data/large/homfam_*.fa` | 13,277 – 93,681 | HomFam protein families (`model/initial.fas`): aldosered, p450, sdr, Acetyltransf, rvp |
| `data/large/homfam_*_sub*.fa` | 3,000 – 30,000 | Random subsets of the HomFam families, used for local development |
| `data/16S.T.fa`, `data/homfam_aldosered.fa` | | Copies of the files in `data/large/` |
| `data/rnasim579.fa` | 579 | RNASim sample from the TWILIGHT repository (`dataset/RNASim.fa`) |

The RNASim, 16S and HomFam files come from the datasets of *Recursive MAGUS* (Smirnov, PLoS Comput
Biol 2021), Illinois Data Bank, doi:10.13012/B2IDB-1048258_V1, released under **CC0**. RNASim was
simulated by Guo, Wang and Kim (arXiv:0912.2326); HomFam is from Sievers et al. (Clustal Omega). The
TWILIGHT sample is from github.com/TurakhiaLab/TWILIGHT (MIT license).

## Synthetic data

Generated by this repository's [simulate.py](simulate.py) (tree-structured DNA, substitutions and
short indels) and [simulate_protein.py](simulate_protein.py): `sim1k`, `sim2k`, `sim5k`, `sim10k`
(1.5 kb), `sim3k_long` (5 kb), `prot2k` (protein). `edge.fa` and `edge_noshort.fa` are `sim1k` with
long unaligned repeats inserted, so the final alignment exceeds 30,000 columns (MAFFT's internal
`alg='M'` switch). That makes them a stress test for exact output.

## BAliBASE 3.0

Not redistributed here, because it has no license statement. `bash bench/get_data.sh --balibase`
downloads it from its official site (Thompson et al., Proteins 2005) into `data/balibase/`.
